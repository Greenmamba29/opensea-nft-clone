## 3. Apply checklist (exact order of operations)

Run via the Shopify admin MCP tools against `grahmos-marketbny.myshopify.com`.

1. **Verify shop context.** `get-shop-info` (and `switch-shop` if needed) to confirm you are on grahmos-marketbny.myshopify.com before any writes.
2. **Snapshot current state.** `search_products` with no filter; record the 7 existing product IDs (they should match the GIDs in `netlify/functions/_shopify-snapshot.ts`).
3. **Archive the demo catalog.** `bulk-update-product-status` → status `ARCHIVED` for the 6 snowboard/wax product IDs from Section 1. Do **not** include the Gift Card (`gid://shopify/Product/15022586396783`). Archive, never delete — the GIDs stay resolvable.
4. **Create the 12 new products.** `create-product` for each Section 2 entry: title, handle, productType, descriptionHtml (the description verbatim), tags, status `ACTIVE`, one variant at the listed price. For the two $0/service SKUs (2.7) and service SKUs generally, set the variant to not require shipping.
5. **Upload images.** Attach one image per product per its image direction (product photos or renders staged to spec). Placeholder renders are acceptable for launch; replace with photography as it lands.
6. **Set inventory.** `get-inventory-levels` to find the location ID, then `set-inventory`: physical goods (2.1–2.6, 2.9–2.11) → 25 units each; service SKUs (2.7, 2.8, 2.12) → untracked inventory (or 999) so they never show sold-out.
7. **Optional but recommended — collection.** `create-collection` "Yard Made" and `add-to-collection` all 12, so the storefront has a flagship shelf to feature.
8. **Verify in admin.** `search_products` (status ACTIVE) → expect 13 products: 12 new + Gift Card. Spot-check one with `get-product` for description/tags/price.
9. **Re-sync the mall catalog.** Run `node scripts/sync-shopify-snapshot.mjs` from the repo root (or trigger the scheduled sync task) to regenerate `netlify/functions/_shopify-snapshot.ts` with the new catalog.
10. **Confirm on the mall.** Check that grahmos-virtual-mall.netlify.app's MarketBNY storefront shows the new products and that no snowboards remain. If the snapshot still shows old entries, confirm the sync committed/deployed and re-run.
